# Grade 10 - Week 9: Programming
## Learning Objectives
- Explain Programming in clear, age-appropriate language.
- Identify the key parts or steps of Programming.
- Apply Programming to a real-life or classroom example.
- Demonstrate: Functions in Python.
- Demonstrate: Predefined Functions.

## Assessment Criteria
- Uses correct terminology when explaining Programming.
- Completes the practice activity accurately.
- Responds to oral questions with clear reasoning.
- Shows understanding of: Functions in Python, Predefined Functions.

## Lesson Timeline
- Introduction - 5 minutes
- Main Activity - 25 minutes
- Wrap-up - 10 minutes

## Introduction (5 minutes)
- Introduce Programming and link it to everyday technology.
- Warm-up questions:
- - Where do we encounter this idea in daily life?
- - How does this help computers work correctly?
- Real-life examples:
- - A classroom example connected to Programming.
- - Link to: Functions in Python, Predefined Functions.
- Teacher: Briefly model the key idea using a quick sketch or object.
- Students: Share one example they know and explain why it fits.

## Main Content (25 minutes)
- Define Programming in clear terms.
- Break down the key components or steps.
- Show a short, concrete example.
- Connect to prior knowledge from earlier lessons.
- Focus point: Functions in Python.
- Focus point: Predefined Functions.
- Discuss a practical application or case study.
- Teacher: Model the process step-by-step and check for understanding.
- Students: Take brief notes and answer a quick concept check.

### Detailed Topic Study
- **Goal (2 min):** Use functions to organize code and apply built-in functions.
- **Functions in Python (9 min):** Define a function, parameters, return values, and scope. Show how to call functions and reuse code.
- **Predefined functions (6 min):** Demonstrate `len()`, `type()`, `sum()`, `min()`, `max()`, and `sorted()`.
- **Guided practice (6 min):** Students write a function to compute average and use built-ins to summarize a list.
- **Check for understanding (2 min):** Identify inputs/outputs for a small function and predict results.

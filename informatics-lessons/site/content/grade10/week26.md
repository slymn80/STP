# Grade 10 - Week 26: Software
## Learning Objectives
- Explain Software in clear, age-appropriate language.
- Identify the key parts or steps of Software.
- Apply Software to a real-life or classroom example.
- Demonstrate: SQL Constraints.
- Analyze how Software affects system design or problem solving.

## Assessment Criteria
- Uses correct terminology when explaining Software.
- Completes the practice activity accurately.
- Responds to oral questions with clear reasoning.
- Shows understanding of: SQL Constraints.

## Key Vocabulary
- software: a key term related to Software
- sql: a key term related to Software
- constraints: a key term related to Software
- input: data entered into a system
- output: results produced by a system
- process: steps that transform input to output
- system: connected parts working together
- accuracy: being correct or free of errors
- diagram: a visual representation of ideas
- protocol: a set of rules for communication

## Lesson Timeline
- Introduction - 5 minutes
- Main Activity - 25 minutes
- Wrap-up - 10 minutes

## Introduction (5 minutes)
- Introduce Software and link it to everyday technology.
- Warm-up questions:
- - Where do we encounter this idea in daily life?
- - How does this help computers work correctly?
- Real-life examples:
- - A classroom example connected to Software.
- - Link to: SQL Constraints.
- Teacher: Briefly model the key idea using a quick sketch or object.
- Students: Share one example they know and explain why it fits.

## Main Content (25 minutes)
- Define Software in clear terms.
- Break down the key components or steps.
- Show a short, concrete example.
- Connect to prior knowledge from earlier lessons.
- Focus point: SQL Constraints.
- Discuss a practical application or case study.
- Teacher: Model the process step-by-step and check for understanding.
- Students: Take brief notes and answer a quick concept check.

## Practice Activity
- Short response: Describe a scenario where Software is important.
- Matching: Pair terms with their definitions.
- Teacher: Circulate, prompt with guiding questions, and correct misconceptions.
- Students: Work in pairs and compare answers.
- Apply: SQL Constraints.

## Assessment
- Observation during activity.
- Oral Q&A: Students explain one part of Software.
- Quick written check: 3 short questions.
- Mini rubric: 3 = accurate and complete, 2 = mostly correct, 1 = needs support

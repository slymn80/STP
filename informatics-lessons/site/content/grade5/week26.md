# Grade 5 - Week 26: Practical work
## Learning Objectives
- Explain Practical work in clear, age-appropriate language.

- Apply Practical work to a real-life or classroom example.
- Demonstrate: Use an ultrasound sensor to locate an object;Use a color sensor to organize the robot's movement.
- Use Practical work vocabulary accurately in short explanations.

## Assessment Criteria
- Uses correct terminology when explaining Practical work.

## Lesson Timeline
- Introduction - 5 minutes
- Main Activity - 25 minutes
- Wrap-up - 10 minutes

## Introduction (5 minutes)
- Introduce Practical work and link it to everyday technology.
- Warm-up questions:
- - Where do we encounter this idea in daily life?
- - How does this help computers work correctly?
- Real-life examples:
- - A classroom example connected to Practical work.
- - Link to: Use an ultrasound sensor to locate an object;Use a color sensor to organize the robot's movement.
- Teacher: Briefly model the key idea using a quick sketch or object.
- Students: Share one example they know and explain why it fits.

## Main Content (25 minutes)
- Define Practical work in clear terms.
- Break down the key components or steps.
- Show a short, concrete example.
- Connect to prior knowledge from earlier lessons.
- Focus point: Use an ultrasound sensor to locate an object;Use a color sensor to organize the robot's movement.
- Teacher: Model the process step-by-step and check for understanding.
- Students: Take brief notes and answer a quick concept check.

### Detailed Topic Study
- **Goal (2 min):** Integrate sensors in a practical task.
- **Key ideas (8 min):** Use ultrasonic sensor to detect objects and color sensor to keep position. Combine readings with if/else logic.
- **Guided demo (6 min):** Show a simple combined logic example.
- **Hands-on practice (6 min):** Students build or simulate a sensor-driven routine.
- **Check for understanding (3 min):** Which sensor measures distance? Which detects the line?
